# Echo Creation - الفضاء البرمجي المتكامل 🚀

هذا المشروع هو تحويل لواجهة React مبدئية إلى تطبيق ويب متكامل ومحسن باستخدام HTML/CSS/JS النقي (Vanilla) و Node.js كخادم خلفي (Backend) مع قاعدة بيانات SQLite.

## الميزات (Features)

*   **فصل الواجهات (Separation of Concerns):** تم تقسيم الموقع إلى صفحات HTML مستقلة لضمان أداء عالي وسيو (SEO) ممتاز.
*   **تصميم عصري:** استخدام إطار عمل Tailwind CSS (عبر CDN) وأيقونات Lucide لتجربة مستخدم فاخرة.
*   **قاعدة بيانات SQLite:** تخزين فعلي للخدمات، الكورسات، منشورات المنتدى والردود، بالإضافة إلى نظام إدارة المستخدمين.
*   **لوحة تحكم محمية:** لوحة تحكم متكاملة لإضافة وتعديل وحذف وحجب الخدمات والكورسات.
*   **نظام توثيق وحماية (Authentication & Security):** استخدام `bcrypt` لتشفير كلمات المرور، و `jsonwebtoken` (JWT) لحماية نقاط الوصول (API Endpoints)، و `helmet` لحماية الـ Headers.

## الهيكل العام للمشروع (Project Structure)

- `server.js`: ملف الخادم الرئيسي (Node.js/Express) يحتوي على مسارات الـ API العامة والمحمية.
- `db.js`: ملف إعداد قاعدة البيانات (SQLite) والجداول مع توليد البيانات الافتراضية.
- `public/`: المجلد الذي يحتوي على ملفات الواجهة الأمامية:
  - `index.html`: الصفحة الرئيسية ومعرض الخدمات.
  - `courses.html`: أكاديمية الكورسات.
  - `forum.html`: منتدى الطلاب.
  - `login.html`: صفحة تسجيل الدخول للمدير.
  - `admin.html`: لوحة تحكم الإدارة (محمية).
  - `css/style.css`: التنسيقات المخصصة والإشعارات التفاعلية.
  - `js/api.js`: دوال الاتصال بالخادم العامة والمحمية بالإضافة لمدير الإشعارات.
  - `js/app.js`: منطق الواجهات العامة (البحث الذكي، الكورسات، إضافة منشورات المنتدى).
  - `js/admin.js`: منطق لوحة التحكم (تسجيل الدخول، إدارة الكورسات والخدمات).

## متطلبات التشغيل (Requirements)

*   Node.js (الإصدار 14 وما فوق)

## خطوات التثبيت والتشغيل (Installation & Running)

1.  تثبيت الاعتمادات (Dependencies):
    ```bash
    npm install
    ```

2.  تشغيل الخادم (Start the server):
    ```bash
    node server.js
    ```

3.  الوصول للتطبيق:
    - قم بزيارة المتصفح على الرابط: `http://localhost:3000`
    - للوصول للوحة التحكم، اذهب إلى `http://localhost:3000/login.html`
    - **بيانات الدخول الافتراضية:**
      - اسم المستخدم: `admin`
      - كلمة المرور: `admin123`

## تقنيات السيو (SEO) والحماية

*   كل صفحة HTML تحتوي على وسوم `<meta>` مخصصة.
*   استخدام `helmet` في Express لحجب الثغرات الشائعة.
*   تنظيف وتشفير الردود باستخدام JWT مع انتهاء صلاحية محددة.
*   منع حقن البيانات عن طريق استخدام البيانات المحضرة (Prepared Statements) في SQLite.
